# Baked crispy snacks (crackers) and pork sheet (moo pan)

## Baked crispy snacks / crackers
Flow: mixing (upright mixer) -> conditioning/proofing (about 80 F / 80 % RH) -> sheeter (2-, 3- or 4-roll) ->
laminator if layered texture -> gauge rolls (about 2:1 reduction per station; the last gauge roll sets piece weight,
moisture and package giveaway) -> rotary cutter + docker -> salt/topping -> pan-on to tunnel oven -> oil spray /
seasoning -> cooling -> packing. Scrap cutters return 30-50 % trim to the sheeter; tied cutters only 1-2 %.

## Pork sheet (หมูแผ่น)
Flow: pork trimming -> mincing -> marinating (sugar, salt, seasoning) -> sheet forming on trays/film -> drying ->
roasting/baking until crisp -> cooling -> cutting -> packing. A meat product: chilled raw material, cooking
temperature as a HACCP critical control point, separate raw and cooked zones.
Reference: ground pork sheets 1.3 and 2.2 mm thick dried with vacuum (10 kPa) + far infrared at 110 C: thin sheets
dry faster but use more energy per kg; thick sheets darken and shrink more. Confirm recipe, times and final aw
with trials.

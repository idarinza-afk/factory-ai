## Sections
1. Scope, references (contract, URS, spec sheets), participants and sign-off.
2. Documentation check: drawings, manuals, certificates, software backups.
3. Mechanical check: dimensions, materials, finish, guards.
4. Electrical/I-O check: wiring, I/O test list, safety circuit test (E-stop, doors).
5. Functional test: each mode (auto/manual), recipes, alarms, interlocks.
6. Performance test: run duration (e.g. 2-4 h or N units), rate, reject rate, OEE criteria.
7. Punch list with priority and owner.
## Rule
Every test line has a measurable acceptance criterion and a pass/fail column.

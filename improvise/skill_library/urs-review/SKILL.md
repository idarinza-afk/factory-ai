---
name: urs-review
description: Turn a customer URS / TOR into a requirement matrix and compliance statement.
tools: search_knowledge, workspace_write
---
## Method
1. Extract every requirement as one line: ID, section, requirement text (short), type (capacity, quality,
   hygiene, safety, utilities, documentation, commercial).
2. For each: compliance (Comply / Partly / Not comply / Clarify) and how it is met.
3. Collect the "Clarify" items as questions to the customer.
4. Save as CSV in the workspace for Excel.
## Note
Scanned documents must be OCR'd first; do not guess unreadable text.

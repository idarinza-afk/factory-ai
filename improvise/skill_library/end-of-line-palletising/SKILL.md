## Method
1. Cases/min and pallet pattern (cases per layer, layers, pallet size EUR 1200x800 / 1200x1000).
2. Palletiser choice: manual (< 4-6 cases/min), robot (flexible, multiple lines), conventional layer palletiser (high speed).
3. Stretch wrapper and pallet label; pallet conveyor buffer for forklift pick-up time.
4. Space: pallet stations, safety fencing for robots (risk assessment), forklift access.
5. Staffing check with staffing for manual options.

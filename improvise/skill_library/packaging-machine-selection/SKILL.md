## Method
1. Product and pack: free-flowing / pieces / liquids; pack type (pouch, tray, bottle, carton); target packs/min.
2. Shortlist by principle: VFFS (powders, granules, snacks), HFFS/flow wrap (bars, single items), thermoforming or tray sealer (meat, ready meals, eggs), rotary fillers (liquids), wrap-around or pick-and-place case packers.
3. Speeds: use supplier ratings; plan OEE 0.65-0.75 for complex packaging machines; machines_required for count.
4. Changeovers: number of formats and target changeover time decide servo vs mechanical.
5. Integration: product orientation, accumulation, rejects, coding and inspection positions.
